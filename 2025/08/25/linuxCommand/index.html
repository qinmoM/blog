Linux系统编程（补充一）命令

发表于2025-08-25|更新于2026-06-08|Linux
|总字数:1.9k|阅读时长:6分钟|浏览量:

b站：满目星何x

常见命令

./FileName
执行当前目录下FileName文件。

ctrl + c可强制终止执行。

外部命令（/bin目录下的文件）：

目录与文件：

ls

  • ls
    显示所有文件。
  • ls –help
    显示ls的帮助文档。
  • ls *asd / ls a*
    查找所有asd结尾的文件。 / 查找所有 a 开头的文件。
参数：

例：ls -ld : 按长格式仅显示目录本身。

  • l
    显示长格式（详细信息）。从前到后分别是：权限，硬连接计数，所有者，所有组，大小，时间，文件名
  • a
    显示隐藏文件。
  • d
    仅显示目录本身。
  • r
    反向排序显示当前目录内容。
  • R
    递归列出目录即子目录全部内容。

touch

  • touch NewFile
    创建一个NewFile空文件。
  • touch 同名文件可以刷新文件的时间。

mkdir

  • mkdir FolderName
    创建FolderName的目录。

which

  • which OrderName
    在环境变量指定位置 查找OrderName命令所在的位置。

cp

  • cp FileName
    复制FileName文件。
  • cp FileName FolderName
    复制FileName到FolderName文件夹里。
  • cp FileName1 FileName2
    根据1创建2。
  • cp -r FolderName
    复制FolderName目录。

rm

  • rm FileName
    删除文件。
  • rm -r FolderName
    删除目录。

rmdir

  • rm FolderName
    只能删除空目录。

mv

  • mv oldName NewName
    重新命名oldName为NewName。
  • mv file /NewPath
    移动file到NewPath位置。

vi

  • vi FileName
    基础的文本编写FileName文件。

cat

  • cat /etc/shell
    查看当前所有shell。
  • cat FileName
    查看FileName文件的内容。
    Ctrl-d来结束。
  • tac FileName
    反转每列显示FileName文件的内容。通常用来查看最新内容，比如日志。

more

  • more FileName
    显示部分文件，按空格向下再显示一行，回车显示一列。
    Ctrl+c或者q终止。

less

  • less FlieName
    与more差不多，不过可以向上或者向下查看。

head

  • head [OPTION] FileName
    显示FileName的前[OPTION]行内容，不写参数默认前10行，没有该文件就向键盘读取。

tail

  • tail [OPTION] FileName
    显示FileName的后[OPTION]行内容，不写参数默认前10行，没有该文件就向键盘读取。

tree（需要安装 sudo snap install tree）

  • tree
    树状显示文件。

wc

  • wc [OPTION] FileName
    计算FileName文件的：-c byte数，-l 列数，-w 字数。

od

  • od -t[OPTION] FileName
    以（c ASCLL字符，d 有符号10进制，……）查看FileName文件。

du

  • du [OPTION] Path
    显示Path路径或目录的占用空间大小。
    需要加 - ：h 按（GB，MB……）等形式显示，s 只显示总站用空间，a 显示所有子目录。

df

  • df [OPTION]
    显示总空间、以用空间、空空间。
    需要加 - ：h 按（GB，MB……）等形式显示……

ln

软链接（符号链接）

不占用磁盘空间，源文件删除则失效。有执行权限但不具有执行的意义，相当于创建了一个快捷方式。（由于）

  • ln -s PathName tempName
    创建一个FileName文件的软链接（快捷方式）名tempName。
硬链接

只能连接普通文件，不能链接目录。不受位置影响，相当于两个文件名指向磁盘的同一个区域。

  • ln FileName tempName
    创建一个FileName文件的硬链接（快捷方式）名tempName。

文件属性、用户以及用户组

chmod

  • 修改文件权限
字母法

chmod u/g/o/a+/-/=rwx 文件

  • u
    表示该文件的所有者
  • g
    位于该文件所有者为同一组，即用户组
  • o
    其他以外的人
  • a
    三者都是
数字法

chmod u/g/o/a+/-/=数字 文件
- 表示 0 ，rwx表示1，用二进制表示：

  • 如rwx对应二进制111，数字为7。
  • r-x对应二进制101，数字5。

chown

  • 修改文件所有者
  • 使用方法：chown 用户名 文件或目录
    用户名： root 为修改用户 / :root 为修改组

chgrp

  • 效果等同chown的用户组
  • chgrp 用户组 文件或目录

其他

echo（bash也内置）

  • echo $SHELL
    查看目前所用shell。

bash内置命令：

cd

  • cd Path
    前往Path路径的目录。
  • cd | cd ~
    回到当前用户的家目录（home）。
  • cd ~UserName/FolderName
    去UserName用户目录里的FolderName目录里。
  • cd -
    回到历史记录里的上一个目录。
  • cd .
    当前目录。（无操作）
  • cd ./FolderName
    进入当前目录下的FolderName目录。
  • cd ../..
    回到上两级目录。

pwd

  • pwd
    查看当前目录。

history

  • history
    查看所有之前输入的命令。

clear

  • clear
    清除终端打印出来的内容。

其他命令

命令格式

  • 命令名 选项(- 字母:-a、–单词:–version等) 参数(如:路径)
    命令执行
  • 外部命令：命令执行时，shell会创建一个子进程并在子进程中执行。
  • 内建命令：相当于调用shell的一个函数，不会创建进程。
    type
  • type -a 命令
    查看是否为内建命令，如果可外部命令会显示…的别名。
    内建命令比外部命令效率高，外部命令一般会创建一个进程。
    find
  • 拥于搜索特定目录下符合条件的文件。
  • 示例
    1. find 路径 -name “文件名”
    2. find 路径 -size 范围
      find /home/user -size +100k
      find /home/user -size -100M
    3. find 路径 -type 类型
      find /home/user -type f
      注意：类型 对应 文件属性 ，但 - 需要用 f 表示。

grep

  • 可以对文本文件匹配字符串。
  • grep [选项] ‘文本’ 文件名
  • [选项]
    1. -v ：不包含匹配文件的所有行。
    2. -n ：显示匹配行和行号。
    3. -i ：忽略大小写。
    4. -r ：递归遍历目录。
    5. -a ：将二进制文件以文本形式搜索。
    6. -w ：显示完全匹配的行。
  • 特殊用法
    尾部加 –color=auto ：高亮显示匹配的关键字。
    chsh
  • 修改当前用户的命令解释器。
    tty
  • 查看终端名字。

帮助手册

help命令

  • 查看命令的功能。
    1. help 内建命令
    2. 外部命令 –help
      man手册
  • 无需联网即可快速查询权威信息。
  • 章节
    1. 可执行程序或shell命令。
    2. 系统调用（内核提供的函数）。
    3. 库调用（程序中的函数，如标准库函数）。
    4. 特殊文件（一般在/dev下）。
    5. 文件格式和规范。
    6. 游戏。
    7. 杂项（包括宏包和规范）。
    8. 系统管理命令。
    9. 内核例程。
  • 用法示例
    man -a passwd : 浏览passwd所有页。（操作时按q + 回车即可翻页）
    man -k passwd : 搜索带有passwd的所有命令。
    man -f passwd : 简述passwd。
    man 数字 passwd : passwd第 数字 页内容。
  • 快捷键
    q : 退出。
    h : 列出所有功能键。
    j / 回车 : 向下翻一行。
    k : 向上翻一行。
    f / 空格 : 下翻一屏。
    b : 上翻一屏。

符号

管道符

依赖匿名管道。

  • 将应该命令的输出当作另一个命令的输入。

  • 输出 | 输入

  • 使用示例
    命令 | grep 关键词

后台进程状态控制

jobs

  • 显示后台进程
    &
  • 将程序放到后台执行。
  • 示例：./a.out &
    fg
  • 切换到前台。
  • 示例：fg +%1（这里1是jobs的作业号）

重定向

类型

  • 标准输入：代码0，默认设备键盘。
  • 标准输出：代码1，默认设备屏幕。
  • 错误输出：代码2，默认设备屏幕。

黑洞文件

  • /dev/null
    输出到此目录下的输出会消失。
  • 一般会与重定向配合使用，将输出不显示。

使用

  • 输出目录 > 文件
    标准正确输出重定向到文件。（覆盖）
  • 输出命令 >> 文件
    标准正确输出追加重定向到文件。
  • 输出命令 2> 文件
    标准错误输出重定向到文件。（覆盖）
  • 输出命令 2>> 文件
    标准错误输出追加重定向到文件。
    • 输出命令 &> 文件
      标准正确和错误输出重定向到文件。（覆盖）
  • 输出命令 &>> 文件
    标准正确和错误输出追加重定向到文件。

    安装方式：sudo apt install sl

    安装方式：sudo apt install bastet
  • asciiquarium
