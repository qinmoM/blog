Linux系统编程（三）目录与文件

类Unix（Linux）系统目录结构

  • Ubuntu没有盘符的概念，只有一个跟目录，所有文件都在它下面。

根目录：

  • bin
    存放可执行文件。例如：date、ls、cat、cp 等可以在bash里直接让命令解释器运行的二进制程序。
  • boot
    存放操作系统（linux内核）启动时的所有必须文件。例如：vmlinuz-开头的核心程序、grub目录等。
  • cdrom
    临时挂载光盘设备。不使用光盘则非必须。
  • dev
    所有硬件设备（包括虚拟设备）的统一接口，系统和程序之间通过这些文件交互（本质是硬件的访问指针）。例如：input文件夹里的mice便是鼠标的文件，使用 sudo cat mice 可以在终端查看鼠标的信息输入。
  • etc
    存储程序的配置信息。例如：passwd 为用户账号信息。
  • home
    用户的目录，存储了所有用户。
  • lib（lib32、lib64、libX32）
    系统与应用使用的所有库，大多存放的是动态连接库（dll），可防止重复代码过多。例如：存放c程序头文件<stdio.h>等标准库的lib文件的文件：libc.so.6，存放在x86_64-linux-gnu目录下（大约14版本之前是直接放在lib下的）。
  • media
    自动挂载外部设备的默认目录。例如：光驱，U盘。
  • mnt
    手动挂载外部设备的自定义目录。
  • opt
    第三方软件的目录。很少使用。
  • proc
    内存中生成的虚拟接口（挂载点）。与进程相关。
  • root
    管理员用户的目录。
  • run
    进程运行时的临时数据。退出进程后便会自动清理。
  • sbin
    管理员的程序或指令。
  • srv
    存放系统服务的数据。
  • sys
    提供内核与用户交互的接口。
  • tmp
    程序运行时的临时文件。重启时会自动删除。
  • usr
    Unix System Resource(系统资源)，核心的共享系统资源目录，也是最大的存放了很多应用程序的目录。例如：
    1. include：目录下存放着 c 的 .h 头文件。
    2. bin：应用程序。
    3. lib(lib64)：应用程序的库。
    4. game：游戏程序。
    5. local：包含用户程序等。
    6. sbin：管理员应用程序。
  • var
    运行时会不断变化的数据。例如：log日志文件，run进程运行时临时数据。

Linux文件类型

  • Linux的文件类型不是通过拓展名区分，而是文件属性区分。

文件属性：

    普通文件（硬连接）。例如：文本文件，可执行程序，.jpg图片。

  • d
    目录文件。例如：/home，/var./log。
  • l
    符号连接文件（软连接）。指向其他文件的快捷方式。
  • b
    块设备文件。例如：硬盘 /dev/sda。
  • c
    字符设备文件。例如：键盘 /dev/input/event0
  • p
    管道文件。进程间临时通信的管道。例如：/tmp/my_pipe。
  • s
    套接字文件。进程间网络通信的接口。
  • 其他文件统一归类为未知文件。

文件颜色

b站：满目星河x

  • 白色：普通文件（.cpp）
  • 绿色：可执行文件（需要用chmod赋值执行权限）
  • 红色：压缩文件
  • 蓝色：目录
  • 青色（淡蓝色）：链接文件
  • 黄色：设备文件
  • 灰色：其他文件

I/O

  • 输入输出时内存和外部设备之间的拷贝数据过程。
  • 输入：设备->内存。
  • 输出：内存->设备。

高级I/O

标准C库提供的I/O称为高级I/O，自带缓冲区。

低级I/O

系统库提供的I/O，不带缓冲（即系统调用，系统编程）。
