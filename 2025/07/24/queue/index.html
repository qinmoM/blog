介绍：

  • 先进先出，后进后出。
  • 依赖数组和链表实现。
  • 对应STL的queue容器。

实现：

顺序队列 sequential queue：

  • 入队时从末尾入队，出队时从开头出队。
  • 如果每次出队都要移动元素，会导致其效率极低，所以我们使用一个指向头元素的指针，每次出队时将指针++，可以达到O(1)的效率。
  • 但是如果使用次数过多，会导致头指针前面的空闲空间太多，所以每次入队时，如果元素已满，可以让尾元素从数组首元素位置继续入队，所以便有了：

环形队列 circular queue：

————将顺序队列的数组结构抽象成环，使数组尾元素后面的指针记为首元素的指针。

  • 使用两个索引，front为队头索引，rear为队尾索引，初始化时都初始化为0。
  • 入队：
    1. 在 arr[rear] 位置入队，并让rear = ( rear + 1 ) % 容量 。
    2. 因为在初始化时，front指针和rear指针指向同一元素，所以如果我们将整个队伍占满才扩容时，会在初始化时一直误判。所以我们可以使rear后面与front前面空出一位元素，当我们判断到rear刚好是front的上一位时就扩容。
  • 出队：
    1. 将 arr[front] 元素出队，并让 front = ( front + 1 ) % 容量 。
    2. 当 front == rear 时，代表队列为空，无法出队。
  • 扩容：
    1. 在扩容时，需要将全部元素拷贝到新位置，并且环形队列靠front判断首元素位置，所以直接从开头位置拷贝便不需要考虑队尾在队头前面的情况。

链式队列 linked queue：

  • 使用链表的队列不会有拷贝内存、抽象环形等操作。
  • 所有操作复杂度均为O(1)。
  • 注：如果是双向循环链表则只需要记录head的指针，head->prev就是队尾，head->next就是队首。

用两个队列实现一个栈：

  • 实现方式：
    1. 本身只需要一个队列就可以栈结构：使用一个记录总元素的size变量，入栈时只需要向后添加；出栈和获取栈顶元素时，循环 size-1 次，依次出队然后入队，再根据需要返回最终队头元素就好。
    2. 使用一个队列记录最终逆序后的顺序，并使用它来出栈和返回栈顶元素；另一个队列用方法一的形式，当前一个队列为空时，这个队列再将结果按排序好的输出到前一个队列中。
    3. 采用不断切换队列的方式，当执行pop和front操作时，将此队列记录到另一个队列中，按需处理最后一个元素。
