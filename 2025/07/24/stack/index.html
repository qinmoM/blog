逆波兰问题（后缀表达式）：

  • 不使用小括号，利用符号的顺序来表示计算的顺序。
  • 规则：
    1. 将符号跟在俩个表达式后面，不同的计算顺序只要将后面符号的顺序调换就行。
    2. 数字顺序不变。
  • 例：
    $$
    (a + b) * b + a + b => a b + b * a + b +
    $$

中缀转后缀表达式：

  • 问题描述：给出一个中缀表达式，转为逆波兰表达式。
  • 如何实现：
    1. 先创建一个存运算符的栈。
    2. 到左括号时，直接压入栈中。
    3. 遇到右括号时，从运算符栈中不断出栈，一直到遇到左括号为止。
    4. 遇到运算符时，反复对比当前运算符和栈顶运算符，如果栈顶运算符优先级高于或者等于当前运算符时，将栈顶全部同级的符号依次出栈，最后将当前符号压入栈中。
    5. 最后将栈内所有符号出栈。

后缀转中缀表达式：

  • 问题描述：给出一个逆波兰表达式，计算其值。
  • 如何实现：
    因为每次遇到符号计算时，计算所用的左右值都是最近储存的两个数字，所以可以利用栈结构：从前开始遍历每个字符， 遇到数字就入栈；遇到符号时出栈最近的两个数字，将其用对应符号计算，并将计算结果入栈。

用两个栈实现一个队列：

  • 实现：
    1. 通过栈结构可以反转输出顺序的特征，让一个栈存储push进来的值；pop和front时，将这个栈里的元素入到第二个栈中，此时第二个栈的顺序就是正确的。在下一次操作push的时候，先将第二个栈的元素入到第一个栈里再入push的值。
    2. 将第一个栈作为push的接口，第二个栈作为pop和front的接口。push时，不需要任何判断就入到第一个栈中；pop和front时，如果第二个栈中没有元素，就将第一个栈的全部元素移动过来，有则输出。

数据结构与算法
一、数据结构 特定关系的数据元素集合。 其逻辑上可分为： 线性结构 散列结构 树形结构 图形结构 二、算法 求解问题的具体步骤，表现为一组有限的指令序列。 算法复杂度1. 大O计法： 随数据规模n的提升，算法执行所耗费的时间或者空间的增长速度。（注意不是计算其占用时间和空间有多大的） 2. 时间复杂度： 随数据规模提升，所消耗时间的增长速度。 常见时间复杂度： O(1)： 数组的随机访问。 哈希表。 O(log n)： 二分查找。 AVL。 红黑树查找。 二叉堆调整。 O(n)： 线性搜索。 O(n * log n)： 堆排序。 快速排序。 归并排序。 O(n^2)： 冒泡排序。 选择排序。 插入排序。 O(2^n)： 子集树。 O(n!): 排列树。 3. 空间复杂度： 随数据规模提升，所消耗空间的增长速度。 常见空间复杂度： O(1)： 两数求和。 BF算法。 O(n)： 求解next数组。 O(n + m)： 合并数组。
