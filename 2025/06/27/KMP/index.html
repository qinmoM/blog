查找函数的写法：

  • 举例解释：
    主：a,b,c,d,e,a,b…
    子：a,b,c,d,e,x
    第一次比较后，子串的1到5（索引0到4）的字符都不相同，所以当子串向后移动时，可直接将子串跳到第6（索引5）位置比较。
    主：a,b,c,a,b,c,a,b,x…
    子：a,b,c,a,b,x
    根据上一个例子可知：第一次比较之后，子串的1到3（索引0到2）不相同，直接将子串跳到第4（索引3）位置。
    并且此时：子串中间的a和b与主串第二个的a和b已经比较过相等，又因为子串中间的a和b和开头的a和b相等，不用比较就知道它们肯定是相等的。所以当跳到这个位置的时候，可以直接让主串的第6（索引5）位置和子串第3（索引2）位置比较。
  • 结论：
    由此可发现：
    1. ==主串的索引可以不用回退==，只将子串的索引回退一定的位置，再与主串做比较。
    2. ==子串回退后的索引等于其最大相同前后缀的元素数量==，并且子串每个字符前面的相同的字符个数不一且不会改变，所以可以给子串计算一个next数组来储存失配后，当前子串的索引在当前位置时要回退的步数。

next数组的求法：

  • 如果索引为0时匹配失败，代表第一位的字符就不匹配，规定写next[0]=-1。（为什么不写=0：在最终的代码实现中，分支只有i++,j++和j=next[x]，所以写为-1可以不用新建新的if分支，只在原来的i++,j++分支里执行即可）
  • 索引为1时匹配失败，说明无相同前后缀，即next[1]=0。
  • 之后要计算公共前后缀的长度，用k记录，遍历到的索引用j记录，则公共前后缀可以表示为：
    $$
    p[0]…p[k-1]=p[j-k]…p[j-1]
    $$
  1. 此时当p[j]等于p[k]时，说明前后缀相同，k要加一，并且j下一位的k也确定等于k+1，即：j++,k++,next[j]=k；
  2. 当p[j]不等于p[k]，我们一般的想法是向前遍历p[k]，直到和p[j]相同，再看他的最大前后缀（注意前面每一位的最大前后缀已经算出），总流程就是：找相等->看前后缀（k=k-1）。但是遍历p[k]太慢了，我们完全可以把总流程变成这样：看==前后缀->找相等==（k=next[k]），将流程进一步缩短。

  • 示例：
    主串： a, b, c, a, b, x, a, b, c, a, b, c
    子串： a, b, c, a, b, c
    基于以上，next数组为： -1 0 0 0 1 2
    当匹配到主串的x时，字串会回退到索引2的c的位置；但是注意到：子串中与x失配的索引4的c和子串索引2的c是一样的，索引4的c已知不匹配，那么索引2的c也一定不匹配，应该继续向前找最大前后缀，又已知next[2] = 0，所以直接跳到0的位置即可。
