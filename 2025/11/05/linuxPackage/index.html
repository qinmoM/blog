相关命令

打包

  • 将一系列文件归档到一个大文件中。也就是打包。

tar

  • tar [选项] 打包文件名 文件
  • 选项
    tar的选项非常特殊，可以不用 - 。
    1. -c ：生成档案文件，创建打包文件。
    2. -v ：显示进度列表。
    3. -f ：指定档案名称。(必须放在所有选项的末尾)
    4. -t ：列出档案包含文件。
    5. -x ：解包。
  • 常用格式
    1. tar -cvf package.tar a b c
      打包a、b、c文件到package.tar。
    2. tar -xvf package.tar
      解包package.tar。
    3. tar -tvf package.tar
      查看package.tar包里的内容。（可以提前查看包内是否有自己需要的内容）

压缩

  • 对打包后的文件压缩和解压缩。

gzip

  • gzip [选项] 文件
    gunzip 文件（效果同 gzip -d 文件）
  • 选项
    1. 无选项 ：默认压缩（不保留源文件）
    2. -d ：解压缩（不保留源文件）
    3. -r ：压缩子目录。
  • 常用格式
    1. tar -zcvf pkg.tar.gz dir/
      同时执行tar和gzip。直接生成压缩包pkg.tar.gz。
    2. tar -zxvf pkg.tar.gz / tar -zxvf pkg.tar.gz -C dir/
      同时执行tar和gzip。直接解压成单个文件。（到dir/目录）
    3. gzip file
      压缩文件。
    4. gunzip / gzip -d file
      解压文件。
