B站：黑马、凛冬将至大白菜

sql语法在不同的数据库中大体相同（单表查询等），但许多细节不同（如多表查询等），以下都为mysql语法。

  • 注意
    1. 在笔记中：
    • []内内容表示可选选项。
    • 可变命名统一为 类型Mode_。如：tableName_、newType_。
    • SQL语句大小写都可以用，但实际中最好使用大写。
    • 约束→默认值→注释→位置，统称为 default column option。
    • modify会清除所有约束，包括 默认值 和 注释。（位置不会）
    1. 关于所有列相关的语句，只要有一下字段，顺序都必须是：
      名字 →类型（INT…）→约束（not null）→默认值（default val_）→注释（comment ‘注释’）→位置（after name_ / first）

数据类型

(m)的m指显示使的长度，只有字段指定zerofill时有用。
(d)表示小数位长度，算在m的长度里，也就是整数长度是m - d。
(n)表示必须给定长度。

整数类型

  • tinyint(m)
    占用1个字节。取值范围-128~127
  • smallint(m)
    占用两个字节。取值范围-32768~32767
  • mediumint(m)
    占用3个字节。取值范围-8388608~8388607
  • int(m)
    占用4个字节。取值范围-2147483648~2147483647
  • bigint(m)
    占用8个字节。取值范围+-9.22*10^18

浮点数类型

  • float(m, d)
    占用4个字节，8位精度。
  • double(m, d)
    占用8个字节，16位精度。

字符类型

  • char(n)
    固定长度，最多255字符。
  • tinytext
    可变长度，最多255字符。
  • varchar(n)
    可变长度，可设置最大长度，最多65535字符。
  • text
    可变长度，最多65535字符。
  • mediumtext
    可变长度，最多2^24字符。
  • longtext
    可变长度，最多2^32字符。

补充

  • 速度对比
    char > varchar > text
  • 使用建议
    char ：长度固定。
    能用varchar的不用text。

日期类型

  • date
    YYYY-MM-DD
  • time
    HH:MM:SS
  • datetime
    YYYY-MM-DD HH:MM:SS
  • timestamp
    时间戳：YYYYMMDD HHMMSS

二进制类型

  • BLOB
    二进制存储。
    只能整体读出。
    不用指定字符集。

SQL语句

  • 注意
    1. 命令的顺序必须是：约束（四种约束顺序随意）→默认值→注释→位置
    2. DQL语句顺序必须是：select → from → where → group → having → order by → limit
    3. select语句的执行顺序：from → where → group by/having → select → order by → limit

DDL

数据定义语言

  • CREATE
  • ALTER
  • DROP

DQL

数据查询语言

  • 注意
    此处除了select命令可以放在开头，其他全部需要跟在后面做子语句使用。
  • SELECT
  • FROM
    用于定位表
  • WHERE
    用于指定条件，还可用于DML语句
  • GROUP BY
    用于将查询结果分组
  • HAVING
    用于将group by的过滤分组结果
  • ORDER BY
    用于排序查询的结果
  • limit
    分页查询

DML

数据操作语言

  • INSERT
  • UPDATE
  • DELETE
  • TRUNCATE

DCL

数据控制语言

权限控制

常用权限

  • all, all privileges
    所有权限
  • select
    查询权限
  • insert
    插入数据
  • update
    修改数据
  • delete
    修改数据
  • alter
    修改表
  • drop
    删除数据库/表/视图
  • create
    创建数据库/表

权限指令

  • GRANT
  • REVOKE

TCL

事务控制语言

  • COMMIT
  • ROLLBACK
  • SAVEPOINT
    详见[[#事务]]篇章。

特殊语句（系统命令、拓展语法）
