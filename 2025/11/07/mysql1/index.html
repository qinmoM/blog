B站：黑马、凛冬将至大白菜

sql语法在不同的数据库中大体相同（单表查询等），但许多细节不同（如多表查询等），以下都为mysql语法。

  • 注意
    1. 在笔记中：
    • []内内容表示可选选项。
    • 可变命名统一为 类型Mode_。如：tableName_、newType_。
    • SQL语句大小写都可以用，但实际中最好使用大写。
    • 约束→默认值→注释→位置，统称为 default column option。
    • modify会清除所有约束，包括 默认值 和 注释。（位置不会）
    1. 关于所有列相关的语句，只要有一下字段，顺序都必须是：
      名字 →类型（INT…）→约束（not null）→默认值（default val_）→注释（comment ‘注释’）→位置（after name_ / first）

约束

主键约束

  • 不可为空
  • 不可重复
  • 一个表只能有一个

单一主键

  • 使用一个列作为主键，该列每个值都不能重复

联合主键

  • 使用多个列作为主键，全部列都相同时看作重复

自增长

  • 一个表只能有一个列为自动增长
  • 类型必须是整数
  • 只能是主键或唯一性约束的列
  • 自增长的列不可删除，只能先去除自增属性后删除

外键约束

  • 可以为空
  • 可以重复
  • 值必须是其他表中唯一约束的键，普遍会写主键

唯一性约束

  • 不可重复，包括空值也只能出现一个
  • 一个表可以设置多个

非空约束

  • 不可为空
  • 可以重复

检查约束（MySQL 8.0.16版本才支持）

  • 自定义约束条件

函数

null值不参与运算。如果表达式中出现了null，则整个表达式返回null。

聚合函数

  • 将一列数据作为整体，进行纵向计算。

用法

常见函数

  • count
    统计数量，为空则不计入
  • max
    最大值
  • min
    最小值
  • avg
    平均值
  • sum
    求和

字符串函数

常用函数

  • concat(s1, s2, … )
    拼接字符串。
  • lower(str) / upper(str)
    转换为小写 / 大写。
  • lpad(str, n, pad) / rpad(str, n, pad)
    用 pad 对 str 左填充 / 右填充 n 个字符串长度。
  • trim(str)
    只去掉头部和尾部的空格。
  • substring(str, start, len)
    返回 str 的 start 位置起的 len 个长度字符串。

用法示例

数值函数

常用函数

  • ceil(x)
    上取整。
  • floor(x)
    下取整。
  • mod(x, y)
    计算 x 取模 y 。
  • rand()
    返回0~1的随机数。
  • round(x, y)
    对数字 x 四舍五入，保留 y 为小数。

用法示例

日期函数

常见函数

  • curdate()
    返回当前日期。
  • curtime()
    返回当前时间。
  • now()
    返回当前日期和时间。
  • year(date)
    返回年。
  • month(date)
    返回月。
  • day(date)
    返回日。
  • date_add(date, interval expr tupe)
    返回 date 加上一个时间值后的日期值。
  • datediff(date1, date2)
    返回 date1 和 date2 之间相差的天数。

使用示例

流程函数

  • if(value, t, f)
    如果 value 为 true ，则返回 t ，反之返回 f 。
  • ifnull(value1, value2)
    如果 value1 为空，则返回 value2 ，反之返回 value1 。
  • case when [val1] then [res1] … else [default] end
    如果 val1 为 true ，返回 res1 ，… 否则返回 default 默认值。
  • case [expr] when [val1] then [res1] … else [default] end
    如果 expr 等于 val1 ，返回 res1 ，… 否则返回 default 默认值。
