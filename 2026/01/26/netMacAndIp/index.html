网络编程（二）mac地址与ip地址

发表于2026-01-26|更新于2026-11-22|网络
|总字数:878|阅读时长:4 分钟|浏览量:

b站：满目星河x

  • 传输信息时，信息先通过ip地址地位网络目标，再通过mac地址定义局域网下的主机，再由不同端口传输给不同应用。

mac地址

  • 表示网卡的id，理论全球唯一。
  • 一般用来表示主机的id，物理地址，不会变动。
  • 由12位16进制构成，共48bit。

ip地址

  • 标识主机的id，此id为虚拟id，会改变。
  • 子网掩码用于标识主机和子网，必须前面全是1，后面全是0。

ipv4

  • 32位bit构成（4字节）。
  • 因其位数限制，通常作为局域网ip。
  • 一个ip分为子网id和主机id，并且需要配合 子网掩码netmask 看，
    其中网段地址为 子网id 后续全0，广播地址为 子网id 后续全1：
    示例：
    ip： 10. 1. 1. 2
    子网掩码： 255.255.255. 0
    其中连续1覆盖的位为子网id：10.1.1
    连续的0覆盖的为主机id：2
    网段地址：10.1.1.0
    广播地址：10.1.1.255
    注：
    • 由于 0 和 255 已经是 网段 和 广播地址 ，所以 主机id 不能为 0 或 255。
    • 此 id 也可写为 10.1.1.2/24 ，这个 24 就表示子网掩码为 255.255.255. 0。

特点

  • 子网id 不同的网络不能直接通信，需要依靠路由器转发。

分类1

A类地址：广域网，通常国家与国家之间。子网掩码255.0.0.0，第一个数字为0127（即二进制最高位为0）。
B类地址：城域网。子网掩码255.255.0.0，第一个数字为128191（即二进制最高位为10）。
C类地址：局域网。子网掩码255.255.255.0，第一个数字为192223（即二进制最高位为110）。
D类地址：多播，224239。
E类地址：保留，240~255。

分类2

  • 分为公网和私网。
  • 只有公网（已注册）可以访问其他网站，私网最终会通过封装成公网来访问。
  • 范围：
    1. A类：只有10.0.0.0~10.0.0.255是私网，其他都是公网。
    2. B类：172.16.0.0~172.31.255.255是私网，其他都是公网。
    3. C类：192.168.0.0~192.168.255.255是私网，其他都是公网。

ipv6

  • 128位bit构成（16字节）。
  • 通常用作公网。

回环地址

  • 127.0.0.1 ~ 127.255.255.254 之间的地址为回环地址，表示此地址指向自己的ip。
  • 可以 ping 本地网络是否好使。

修改ip地址

  • windows在中，进入网络和共享中心，点击更改适配器设置，右键以太网选属性，修改即可。
  • ubuntu中，输入ifconfig，查看自己的设备名称；输入sudo ifconfig 设备名称 目标ip netmask 目标子网掩码。
    自动获取ip：sudo dhclient
    拨号获取公网ip（不能使用虚拟机）：sudo pppoeconf

端口 port

  • 由2字节（065535 无符号短整型）构成。其中01023为知名端口（如FTP-21），应使用除这些外的动态端口。
  • 标识：要接收消息的应用程序（进程）缓冲区；每个端口都有一个端口号。
  • 由于进程号每次启动都会变，所以只能通过端口标识。
  • 一个程序可以有多个端口，但多个程序不能有同一个端口。
  • tcp 和 udp 维护各自独立的端口号，及 tcp 的 8000 端口和 udp 的 8000 端口不一样。
